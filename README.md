# hiromani Portfolio

日本語版の個人ポートフォリオサイトです。

## ローカルで確認
`index.html` をブラウザで開いてください。

## XのIDを設定
`index.html` の Contact セクションにある `YOUR_X_ID` を自分のX IDに置き換えてください。
`href="https://x.com/YOUR_X_ID"` と表示テキスト `@YOUR_X_ID` の両方を変更します。

## アバター画像
`assets/images/avatar.png` は提供された画像をそのままコピーしたものです。表示時のトリミングはCSSの `object-fit` / `object-position` で行っています。元画像自体は加工していません。

## 公開
GitHubリポジトリにアップロードし、Settings → Pages から公開元を設定してください。
